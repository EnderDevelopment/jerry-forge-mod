# Jerry's Forge Mod

Jerry's Forge Mod is a simple Minecraft mod designed for Minecraft version 1.20.1 using the Forge mod loader. This mod is created to demonstrate the basics of modding for Minecraft using Forge. It serves as a starting point for developers looking to create their own mods.

## Install

1. Download the mod file (jerrymod-1.0.0.jar) from the releases section of this GitHub repository.
2. Place the downloaded jar file into the `mods` folder of your Minecraft instance. If the `mods` folder does not exist, create it in the root directory of your Minecraft installation.
3. Launch Minecraft and select the Forge profile for version 1.20.1.

## Use

1. Launch Minecraft with the Forge profile for version 1.20.1.
2. The mod will be active in your game. Since this is a basic mod, it does not add any new items, blocks, or functionality. It serves as a template for further development.
